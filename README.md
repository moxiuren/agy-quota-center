# AGY 多账号配额管理与跨终端热重载中心 (agy-quota-center)

> 高性能 Rust 原生构建 | Windows 控制台自动化注入 | 跨会话零冲突热重载 | 凭据安全隔离

---

## 项目简介

**agy-quota-center** 是专为 Google Antigravity (`agy`) CLI 打造的多账号配额监控与无缝热重载管理工具。

当单个 Google 账号配额耗尽时，无需繁琐地手动退出所有正在进行的终端会话。本工具可一键切换账号，并通过 **Win32 控制台自动化协同技术**，无感重载当前运行中的全部 `agy` 会话，并各自精准恢复各自的历史会话上下文（Zero-Collision Resumption）。

---

## 核心特性

- **极速原生性能**：纯 Rust 静态编译，仅约 1.7MB 单 EXE，零外部依赖，毫秒级响应。
- **跨终端协同热重载**：
  - 通过 Win32 Console API（`WriteConsoleInput`）向外部后台终端精准下发协同中断信号。
  - 自动规避杀死当前运行的操作窗口（祖先进程链溯源保护）。
  - 超时自愈机制（1.2s 兜底终止），确保挂起的会话不会卡死。
- **独立会话 ID 精准恢复 (Zero-Collision Resumption)**：
  - 传统 `agy -c` 在多个终端并发恢复时会随机抢占同一个会话，导致 `Conversation already open` 互斥锁死。
  - 本工具采用**双层嗅探引擎**（控制台屏幕缓冲区解析 + 运行态日志 PID 映射），精确提取每个窗口专属的 Conversation UUID。
  - 重载时为每个窗口单独注入 `agy --conversation=<UUID>`，实现多会话完全独立互不冲突地恢复。
- **全局额度对比大盘**：
  - 并发同步所有账号的 Gemini Flash / Gemini Pro 及 Claude / GPT 模型的 5 小时限额与每周限额。
  - 自动计算并高亮可用额度最充沛的账号。
- **系统级原生集成**：
  - 走标准 Google OAuth 2.0 流程，凭据直接存入 Windows 凭据管理器 (`gemini:antigravity`)。
  - 自动同步更新 `~/.gemini/` 配置目录。

## 构建与编译

本项目采用 Rust 编写：

```bash
# 进入 Rust 源码目录
cd src-rust

# 编译 Windows 优化发行版本
cargo build --release
```
编译产物位于 `src-rust/target/release/agy-quota-center.exe`。
